Can I use my Claude subscription instead?

No — subscriptions only work inside Anthropic's own apps. Use an API key from console.anthropic.com. Keys are stored only on this device and sent only to the provider you configure.

Behavior

Backup
Snapshots live only in this extension's private storage on this device — nothing is uploaded. To inspect them: your browser's extensions page → Tab Librarian → "service worker" → Console → chrome.storage.local.get('backups'). Export downloads the tree as a JSON file; import merges one back and never deletes anything.
